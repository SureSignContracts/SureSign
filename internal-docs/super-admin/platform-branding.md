# Platform Branding (Super Admin)

## Where to find it

Admin panel → **SureSign**.

## What you can set

- **Platform logo** and **site favicon**.
- **Letterhead header and footer images**, used on generated documents where
  platform-level branding applies.
- A **full letterhead PDF**, with a test-generation action to preview how it
  renders.
- Email header/footer branding assets used in transactional emails.

This is separate from an individual organisation's own branding (documented in
the public User Guide's Company Branding page), which controls that
organisation's own logo, colours, and letterhead on its documents.
