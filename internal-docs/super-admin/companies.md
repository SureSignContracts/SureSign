# Companies (Super Admin)

## Where to find it

Admin panel → **Companies**.

## What you can do

- View every organisation on the platform, with their project and user counts.
- Open a company to see its projects and add a new project to it.

!!! note "Adding a brand-new company is not currently available in the interface"
    The Companies page shows an **Add Company** button, but it does not
    currently open a form or create anything — it has no effect today. New
    organisations must currently be set up outside the standard admin
    interface. If you need a new organisation created, contact your SureSign
    platform provider rather than expecting to self-serve this from the
    Companies page.
