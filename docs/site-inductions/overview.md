# Site Inductions

## What this is

Site Inductions record induction sessions held on a project — date,
optional session title, company/trade, and the number of people inducted
— so there is a reliable, auditable trail of who was inducted onto site
and when.

Each record represents **one induction session**, not one individual
person. If two separate sessions happen on the same day (for example, a
morning induction and a separate afternoon induction for a different
subcontractor), record two entries.

## Who can use it

Any authenticated user with access to the project — including the Client
role, not just Admin/Super Admin — can create site inductions.

## Where to find it

Project → **Health & Safety → Site Inductions**.

## What you can record

- Induction date
- Session title (e.g. Morning Site Induction, Subcontractor Induction)
- Company / trade
- Number inducted
- Notes
- Evidence — a sign-in sheet photo or similar

## What this is not

Site Inductions does not record individual worker identities — only a
session-level headcount. It does not manage occupational health records,
training history, or competency matrices.

## Friday Packs

Site Inductions feeds the Friday Pack's Site Inductions section
automatically — every session recorded within a Friday Pack's Monday to
Friday reporting week appears there, along with a total inducted figure
for the week. See [Friday Packs](../friday-packs/overview.md).
