# Activity History

## Project activity

Every project's **Overview** page shows a feed of recent activity: uploads,
document generation, status changes, and similar events, each with an icon and
timestamp.

## Trade package activity

Each trade package's workspace has its own **Activity** tab, scoped to that
package.

## Administrator activity

Administrator accounts see a **Recent Activity** feed on their own dashboard.
