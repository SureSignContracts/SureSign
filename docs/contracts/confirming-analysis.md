# Confirming Analysis

## What this is

Confirming is the step that makes an AI analysis "count." Until you confirm, an
analysis is just a suggestion sitting alongside your contract.

## Who can use it

Super Admin and Admin users.

## Where to find it

From the analysis review screen (see [Reviewing AI Results](reviewing-ai-results.md)),
select **Confirm & Save Analysis**.

## How to confirm

1. Review every section of the analysis.
2. Correct any values that need it.
3. Select **Confirm & Save Analysis**.
4. If this analysis would overwrite existing contract data, read the warning
   shown and confirm you want to proceed.

## What happens after you confirm

- The analysis status changes to **Confirmed**.
- The confirmed data becomes available to the rest of SureSign — for example,
  [programme milestones](../programme/overview.md) can be seeded from it, and
  statutory payment dates in [Commercial](../commercial/overview.md) may use
  confirmed contract terms.
- You can generate a **Contract Intelligence Brief** (a summary document) from
  a confirmed analysis.
- You can still start a new analysis later (for example after a contract
  amendment) — confirming one analysis does not prevent running another.

## Important

!!! important
    Confirming does not create a binding legal record — it tells SureSign to
    treat this extracted information as the current best data for this
    contract. Always satisfy yourself the values are correct against the actual
    contract document first.
