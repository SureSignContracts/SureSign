# Reviewing AI Results

## What this is

Once an analysis completes, SureSign shows the extracted information in a
review screen, organised into collapsible sections, before anything is applied
to your contract.

## Where to find it

Select **View Result** on a completed analysis from the contract's Contracts
page, or from the AI progress indicator once it shows "Analysis complete."

## What you will see

The review screen presents the extracted data in sections, which you can expand
or collapse:

- **Summary** — a short plain-language summary of the contract.
- **Fields** — extracted values such as parties, contract sum, retention, and
  payment terms.
- **Workflows** — payment-related rules the AI identified.
- **Documents** — references to schedules or appendices the AI noticed.
- **Dates** — key contract and programme dates.
- **Risks** — anything the AI flagged as a risk or unusual clause.
- **Missing items** — information the AI could not find in the document.

## How to review

1. Read through each section.
2. Check extracted values against the actual contract document (use the
   download/preview action if you need to see the source file again).
3. Correct any values that look wrong before confirming — the review screen
   lets you edit extracted fields.

## What to do next

Once you are satisfied the information is accurate, go to
[Confirming Analysis](confirming-analysis.md).

!!! warning
    If your contract already has data in fields that this analysis would
    overwrite, SureSign shows an overwrite warning before you confirm. Read it
    carefully — confirming will replace those existing values.
