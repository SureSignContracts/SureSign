# Creating a Contract

## Who can do this

Super Admin and Admin users.

## Where to find it

Open a project, select **Contracts**, then **New Contract** (or similar create
action).

## How to create a contract

1. Enter a **Title** (required).
2. Choose a **Contract Type** (required) — main contract, subcontract,
   consultant appointment, or supplier agreement.
3. Optionally enter a **Reference Number**.
4. Enter the **Contracting Party** (the other party to the contract).
5. Enter the **Form of Contract** (for example "JCT SBC", "NEC4").
6. Enter the **Contract Sum** and **Currency**.
7. Enter **Retention %** and **Retention Cap %**, if applicable.
8. Enter **Payment Terms (days)**.
9. Enter **Execution Date**, **Commencement Date**, and **Completion Date**.
10. Optionally enter **Defects Liability Period** and **Liquidated Damages**.
11. Save.

Only Title and Contract Type are required — the rest can be filled in now,
extracted later via [AI analysis](ai-analysis.md), or edited at any time.

## What happens after you save

The contract appears in the project's Contracts list with status **Draft** (or
whatever status you set). Its terms (retention, payment terms) are used later
when statutory payment dates and retention are calculated in
[Commercial](../commercial/overview.md).

## Common mistakes to avoid

- Entering the wrong currency code — this affects how amounts display
  throughout the project.
- Forgetting to set retention or payment terms if you already know them, then
  relying on AI analysis to supply values it may not find in the document.

## What to do next

- [Upload the executed contract document](uploading-a-contract.md).
- Or edit the contract's fields directly if you already know its terms.
