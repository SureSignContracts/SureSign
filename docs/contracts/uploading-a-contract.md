# Uploading a Contract

## What this is

Attaching the actual contract document (PDF, Word, or text file) to a contract
record, so it can be stored, downloaded later, and optionally analysed by AI.

## Who can use it

Anyone with access to the project (including the ordinary Client account
role, not just Admin/Super Admin).

## Where to find it

On the project's **Contracts** page, use the attach/upload file action on the
contract you want to add a document to.

## Supported file types and size

- Supported document types generally include PDF, Word (DOC/DOCX), Excel
  (XLS/XLSX/CSV), plain text, and common image formats.
- The maximum upload size is set by your Super Admin (50MB by default).
- SureSign checks uploaded files for a supported format and safe processing.
  Files that fail this check are rejected with a message such as **"This file
  type is not supported"** or **"The uploaded file does not match its
  extension."** — nothing further is stored if a file is rejected.

## How to upload

1. Open the contract.
2. Select the attach/upload action.
3. Choose the file from your computer.
4. Confirm the upload.

## What happens after you upload

- The file is stored against the contract and available to download later.
- You can now start [AI Analysis](ai-analysis.md) on this document, if your
  organisation has AI enabled.

## Common mistakes to avoid

- Uploading a scanned image of a contract with very poor image quality — AI
  analysis works from extracted text, so a clean, text-readable PDF or Word
  document gives better results than a low-quality scan.
- Uploading the wrong version of a document — if the contract has been
  re-issued or amended, upload the latest executed version.

## What to do next

[Start AI analysis](ai-analysis.md) on the uploaded document, or continue
filling in the contract's fields manually.
