# Dashboard

Your dashboard is the organisation-wide starting point you land on after
signing in. It answers "what requires attention across the organisation
today," so you can triage before opening any single project, rather than a
summary of recent activity.

## Tenant dashboard

Found at the top of the tenant workspace (Dashboard in the sidebar). The page
opens with a greeting and a compact summary of what needs attention, so you
can gauge your whole organisation's status before scrolling into any one
section.

- **Attention summary**: four compact counts — Overdue, Due Today, Due Soon,
  and Commercial Deadlines — each linking straight to the relevant filtered
  view below.
- **Needs Attention**: one prioritised queue of overdue and soon-due items
  across every accessible project, RFIs, variations, payment deadlines, risk
  reviews, delivery documents, and programme milestones, sorted most overdue
  first. Shows the top 5 highest-priority items by default, with a "View all"
  option to see the rest. Filter by urgency, project, or record type — once a
  filter is applied, every matching item is shown regardless of the top-5
  default. Select any row to open that exact record. When nothing is overdue
  or due soon, this section shows "All caught up" rather than an empty table.
- **Project Map**: shows your organisation's projects on a map, using the
  coordinates entered on each project (see
  [Creating a Project](../projects/creating-a-project.md)). A project only
  appears once it has coordinates — SureSign never guesses a location from
  an address, so add coordinates manually if you want a project to show up
  here. Click a marker to see the project's name, status, and open action
  counts, with a link straight into that project. If some projects have
  coordinates and others don't, a note shows how many of the total are
  shown. Each marker's popup also offers a **Google Maps** shortcut that
  opens the exact project location in Google Maps in a new tab.
- **Portfolio Health**: Active Projects, Projects With Overdue Items, Total
  Overdue Items, and Items Due Soon, all calculated from the same queue above
  so the counts always agree with what you see there.
- **Commercial Position**: a compact read on Outstanding balance, Retention
  Held, applications awaiting certification, and commercial deadlines due,
  linking through to [Global Commercial](../commercial/global-overview.md)
  for the full operational picture. If your organisation has projects in more
  than one currency, amounts are shown per currency rather than combined.
- **Recent Activity**: a short organisation-wide feed of recent project
  activity, where the project and actor are shown alongside each entry, with
  an option to show more.

Dashboard is read-only. It never lets you create, edit, or respond to a
record directly. Every action link takes you to the exact record in its
project so you can act on it there.

!!! note
    Accounts with broader administrative access see a different dashboard,
    focused on platform administration rather than day-to-day project work.

## Where activity for a specific project lives

Project-level activity (uploads, status changes, document generation, and so
on) appears on that project's **Overview** page in full, alongside the short
organisation-wide summary shown on the global Dashboard.
