# Dashboard

Your dashboard is the summary view you land on after signing in, giving you a
quick read on what's active and what needs attention.

## Tenant dashboard

Found at the top of the tenant workspace (Dashboard in the sidebar).

- A greeting with your first name.
- **Stat tiles**: Active Projects (with total project count), Open RFIs,
  Pending Variations, Docs This Month, and Payment Apps. Each tile links to the
  relevant list (Projects, Site Admin, Commercial, or Documents).
- **Recent Projects** — your most recently created projects, with status badge.
- **Open RFIs** — a short list of open RFIs across your projects, with the
  project name and date raised.

There are no separate risk-summary or upcoming-deadline widgets on this
dashboard today. For deadlines, use a project's [Calendar](../calendar/overview.md);
for risks, use a project's [Risk Register](../risks/overview.md).

!!! note
    Accounts with broader administrative access see a different dashboard,
    focused on platform administration rather than day-to-day project work.

## Where activity for a specific project lives

Project-level activity (uploads, status changes, document generation, and so
on) appears on that project's **Overview** page, not on the global dashboard.
