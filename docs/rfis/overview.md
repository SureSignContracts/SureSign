# RFIs (Requests for Information)

## What this is

An RFI is a formal question raised during a project, tracked from question
through to response and closure.

## Who can use it

Super Admin and Admin create, respond to, and close RFIs. Client users can
view them.

## Where to find it

Project → **RFIs**.

## In this section

- [Creating an RFI](creating-an-rfi.md)
- [Responding and Closing](responding-and-closing.md)

## Statuses

| Status | Meaning |
|---|---|
| Draft | Being prepared. |
| Open | Raised, awaiting response. |
| Pending Response | Response is due/overdue. |
| Responded | A response has been recorded. |
| Closed | Finished with. |

## Priority levels

Urgent, High, Normal, Low.

## What this affects

RFIs and their response-due dates appear on the project
[Calendar](../calendar/overview.md), and an RFI's status contributes to your
dashboard's "Open RFIs" figure.
