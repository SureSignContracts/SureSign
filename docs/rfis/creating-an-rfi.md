# Creating an RFI

## Who can do this

Super Admin and Admin.

## How to create an RFI

1. Select **New RFI**.
2. Enter the **Subject** and your question/description.
3. Choose a **Priority** (Urgent, High, Normal, Low).
4. Enter the **Raised Date** and a **Response Required By** date.
5. Note whether there is a **Programme Impact** or **Cost Impact**.
6. Save.

## What happens after you save

The RFI appears in the project's RFI register with status Open, and its
response-due date appears on the project [Calendar](../calendar/overview.md).

!!! note
    Assigning an RFI to a specific person is not currently a reliable feature
    in the interface — treat the response-due date and priority as the main way
    to track ownership until this is available.
