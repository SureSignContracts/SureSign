# Toolbox Talks

## What this is

Toolbox Talks record short construction site safety briefings — topic,
date, presenter, attendance, and evidence — so there is a reliable,
auditable trail that a briefing took place.

## Who can use it

Any authenticated user with access to the project — including the Client
role, not just Admin/Super Admin — can create toolbox talks.

## Where to find it

Project → **Toolbox Talks**.

## What you can record

- Topic / title (e.g. Working at Height, Manual Handling, PPE)
- Date and optional start time
- Location
- Delivered by (presenter name)
- Trade / subcontractor / team
- Key points / summary
- Attendee count
- Evidence — signed attendance sheets, photos, or PDFs

## Statuses

Draft, Submitted, Approved.

## What this is not

Toolbox Talks does not manage individual worker identities or capture
digital signatures — attendance is recorded as a count, and evidence
(such as a signed paper attendance sheet) is attached as a file.
