# Generated Documents (Commercial)

Commercial records that produce a document you can download:

| Record | Document | How it's produced |
|---|---|---|
| Payment Application | Payment Application PDF | Generate action on the application |
| Payment Application (certified) | Payment Certificate | Automatically, when you certify |
| Payment Application (certified) | Excel workbook | Generate Excel action |
| Payment Notice | Payment Notice PDF | Automatically, when the notice is issued |
| Pay Less Notice | Pay Less Notice PDF | Automatically, when the notice is issued |
| Variation | Variation Order PDF | Generate action on the variation |
| Final Account | Statement of Account | Generate Statement action |
| Final Account (certificate issued) | Final Certificate | Generate Final Certificate action |

All generated documents are also saved to the project's
[Documents](../documents/overview.md) area, so you can find them again later
even if you navigate away from the originating record.
