# Application Valuations

## What this is

The detailed breakdown behind a payment application's headline figures —
measured works, variations, and materials on site — and how they roll up into
the amount applied for.

## Where to find it

Open a payment application from the Payment Applications list to see its full
valuation detail.

## What you will see

| Line | Meaning |
|---|---|
| Measured Works Total | Value of physically completed work for the period |
| Linked Approved Variations | Value of approved variations included in this application |
| Manual Variations Total | Any variation value entered directly on the application |
| Materials on Site Total | Value of unfixed materials delivered to site |
| Gross Valuation | Sum of the above |
| Less: Retention | Retention withheld from the gross valuation |
| Net Valuation | Gross valuation minus retention |
| Less: Previous Certified | Sum of all previously certified applications |
| Amount Applied For | The net new amount being claimed this time |
| Total Due incl. VAT | Where applicable, the VAT-inclusive figure |
| Previous Paid Value | Total already paid on prior applications |
| Previous Retention Held | Retention carried forward from prior applications |
| Certified Amount | Shown once the application has been certified |
| Paid Amount | Shown once the application has been marked paid |

## How to use it

Review each line before submitting or certifying an application. If the
figures look wrong, correct the application while it is still in Draft (or
withdraw it back to Draft if it has already been submitted).
