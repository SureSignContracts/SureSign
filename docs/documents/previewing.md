# Previewing Documents

## How to preview

Select a document in the Documents list to open its preview.

## What you will see, by file type

| File type | Preview experience |
|---|---|
| PDF | Shown inline in the preview window. |
| Image (JPG, PNG, WEBP, GIF, SVG) | Shown inline. |
| Some generated/converted documents | Shown inline as formatted content. |
| Word documents (DOCX) and other unsupported types | **Preview not available for this file type.** Use Download instead. |

## Why some files download instead of previewing

Not every file type can be safely rendered in the browser. Where SureSign
cannot generate an inline preview, it tells you clearly and offers **Download**
so you can open the file with the appropriate application on your own device.

## If a preview fails to load

You will see: **"Could not load preview. The file may be missing or
inaccessible."** See
[Troubleshooting: Preview unavailable](../troubleshooting/previews.md).
