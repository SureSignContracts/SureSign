# Folders

Every project has a set of standard folders created automatically, covering
areas such as contracts, commercial, payment applications, variations,
notices, RFIs, meetings, QA reports, snagging, closeout, adjudication, site
reports, and general documents. Trade packages get their own set of standard
sub-folders for subcontract onboarding documents (tender enquiry, drawings,
specifications, pricing, contract draft, correspondence, returned tender, and
executed contract).

Use the folder list on the left of the Documents page to browse into a
specific area before uploading, so files land in the right place.
