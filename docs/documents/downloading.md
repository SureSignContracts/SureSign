# Downloading Documents

Select **Download** on any document, whether or not it can be previewed
inline. If a preview is showing, an **Open in New Tab** option is also
available.

If a download does not start, you will see a **"Download failed."** message —
see [Troubleshooting: Downloads](../troubleshooting/document-generation.md).

## Deleting a document

Deleting a document does not permanently erase it. SureSign removes it from
your active document list, but the file itself is retained so it can be
recovered if needed — contact your Super Admin or Admin if you need a deleted
document restored.
