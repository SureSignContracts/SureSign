# Documents

## What this is

SureSign keeps two kinds of files together in one place for a project:
**uploaded documents** (files you add yourself) and **generated documents**
(PDFs and Excel workbooks SureSign produces, such as payment certificates and
variation orders).

## Who can use it

Administrator accounts upload, preview, and delete documents. Client users can
view and download them.

## Where to find it

- Project level: Project → **Documents**, with an **Uploaded Files** view and a
  **Generated Documents** view. Uploading, folders, and generating documents
  all happen here.
- Organisation-wide: **Documents** in the tenant workspace Workspace menu is a
  search and discovery page across every project you can access. See
  [Global Documents](global-search.md).
