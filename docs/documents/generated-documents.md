# Generated Documents

SureSign automatically produces certain documents as PDFs or Excel workbooks,
branded with your organisation's logo and letterhead. These appear in the
**Generated Documents** view of a project's Documents page as soon as they are
created, alongside any manually uploaded files.

See [Commercial: Generated Documents](../commercial/generated-documents.md) for
the full list of which records produce a document and how.
