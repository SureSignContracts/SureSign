# Risks

## What this is

A risk register entry for a project or trade package: a potential issue, its
likelihood and impact, mitigation, and an owner.

## Who can use it

Any authenticated user with access to the project — including the Client
role, not just Admin/Super Admin — can create and manage risks.

## Where to find it

- Project level: Project → **Risk Register**.
- Trade package level: open the trade package and use its Risks section.

## How to create a risk

1. Select **Create Risk**.
2. Enter a **Title**, **Description**, and **Category**.
3. Choose a **Severity** (Critical, High, Medium, Low) and **Probability**.
4. Enter the **Risk Owner** and a **Recommended Action** / **Mitigation**.
5. Choose a **Status** (Open, In Progress, Resolved).
6. Enter a **Review Date**.
7. Save.

## AI-generated versus manual risks

Some risks may be created from a confirmed contract or subcontract AI analysis
(shown with an AI indicator), where the analysis identified something worth
flagging. Others are added manually by a user. Both are managed the same way
once created; check the source indicator if you need to know where a
particular risk came from.

## What this affects

Risks with a review date appear on the project [Calendar](../calendar/overview.md).
