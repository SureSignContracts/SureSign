# Settings and Branding

Your organisation's settings cover branding, company information, and your own
password. See [Company Branding](company-branding.md).

## Where to find it

Tenant workspace → **Settings** (in the sidebar footer profile menu, or via
Settings in the main menu).

## In this section

- [Company Branding](company-branding.md)

!!! note
    Platform-wide configuration is managed separately by SureSign
    administrators and is not covered in this guide.
