# Troubleshooting: Document Generation

## A generated PDF or Excel file did not download

- Try the generate/download action again.
- Check the record's Documents/generated documents list — the file may already
  have been generated and just needs to be opened from there rather than
  re-generated.
- If it still fails, contact your Super Admin or Admin.

## Subcontract package generation shows unresolved placeholders

If the generation result screen reports unresolved placeholders, open the
generated file and check which fields are missing, then check whether the
underlying project, trade package, or contractor details need completing
before regenerating.

## A trade package template could not be found

If package generation tells you no suitable template exists (for example "no
Master Package template found"), ask your Admin to upload the required
document template.
