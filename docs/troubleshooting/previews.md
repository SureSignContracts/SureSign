# Troubleshooting: Previews

## "Preview not available for this file type"

Some file types (notably Word documents that have not been converted to a
preview format) cannot be shown inline in the browser. Use **Download** to open
the file with the appropriate application on your device.

## "Could not load preview. The file may be missing or inaccessible."

Try again after a moment. If it keeps happening, the file may have been
deleted, or there may be a temporary access problem — contact your Super Admin
or Admin if the file should still exist.

## "Download failed."

Try again. If it persists, check your network connection, or contact your
Super Admin if the file may have been removed.
