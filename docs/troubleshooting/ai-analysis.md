# Troubleshooting: AI Analysis

## "AI features are disabled."

Your organisation's administrator has switched off AI features. Contact them
if you need this enabled.

## "An analysis is already in progress for this contract."

You (or someone else) already started an analysis on this contract or trade
package that has not finished yet. Wait for it to complete before starting
another.

## "AI analysis rate limit exceeded. Please try again later."

You have started too many analyses within an hour. Wait before trying again.

## Analysis failed

See [Failed Analysis](../ai/failed-analysis.md). Try **Re-parse** first if
offered (this does not use additional AI usage); otherwise start a fresh
analysis, and consider re-uploading a cleaner copy of the document if the
original was a poor-quality scan.

## I cancelled an analysis and it still seems to have used AI usage

If you cancel after an analysis has already started processing (not while it
was still only queued), SureSign tells you the in-progress usage may still be
charged. This is expected — cancelling before processing starts is free,
cancelling during processing may not be.
