# Troubleshooting: Notifications

## I don't see a notification bell

The bell is shown to every account (Client, Admin, and Super Admin alike) in
the tenant workspace's top bar. If you genuinely don't see it, check a
project's Overview activity feed instead and contact support if the bell
still doesn't appear after signing out and back in.

## I expected an email but did not receive one

An email only sends if all of the following are true: the event is enabled in
your platform's notification settings, your organisation's email sending is
configured, and there is a valid recipient (your organisation's contact email,
or a Client-role user's email). If any of these is missing, no email is sent —
but the action you took (for example submitting a payment application) still
succeeds normally. Ask your Super Admin to check the relevant setting.

## A notification won't go away

Use the dismiss control on the notification, or **Mark all as read** /
**Clear read notifications** from the bell's options menu.
