# Reports

## What this is

A cross-project view for pulling together summary figures rather than opening
each project individually.

## Where to find it

**Reports** in the sidebar's Tools section.

## What you'll see

- Summary tiles: Total Contract Value, Certified to Date, Outstanding Balance,
  and Open RFIs, all totalled across every project you have access to.
- **Commercial Summary** — select **View** to see a table of every project's
  contract value, amount certified, amount paid, outstanding balance,
  retention held, and approved variations value, side by side.

Other report types (Project Status, RFI Summary, Document Register, Financial
Forecast) are listed but marked **Coming soon** — they are not available yet.
