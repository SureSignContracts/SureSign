# QA Reports

## What this is

Quality assurance inspection records for a project.

## Who can use it

Super Admin and Admin create and manage QA reports. Client users can view them.

## Where to find it

Project → **QA Reports**.

## How to create a QA report

1. Select **Create** (or **Edit** an existing one).
2. Enter the **Title**, **Inspection Type**, and **Area**.
3. Enter the **Inspector** and **Inspection Date**.
4. Choose a **Status** and record the **Result**.
5. Enter **Observations** and any **Corrective Action** needed.
6. Tick **Follow-up Required** if applicable.
7. Save.

## Statuses

Draft, Open, Failed, Passed, Closed.

## Deleting a QA report

A delete action is available, with a confirmation prompt.
