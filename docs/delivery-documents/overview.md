# Delivery Documents

## What this is

A register of documents required or expected to be delivered for a project or
trade package — for example warranties, certificates, or O&M manuals — tracked
by status rather than as a file-upload area itself.

## Who can use it

Any authenticated user with access to the project — including the Client
role, not just Admin/Super Admin — can manage delivery documents.

## Where to find it

- Project level: Project → **Delivery Documents**.
- Trade package level: the Documents tab within a trade package's workspace.

## How to add a delivery document

1. Select **Add**.
2. Enter a **Title**, **Category**, and **Revision**.
3. Enter a **Due Date** and, if applicable, an **Expiry Date**.
4. Save.

!!! note
    This register tracks metadata (title, category, dates, status) about a
    required document — it does not include its own file upload. If you need to
    attach the actual file, upload it via [Documents](../documents/overview.md)
    and treat the delivery document entry as the tracking record for it.

## Statuses

Required → Pending → Submitted → Under Review → Approved / Rejected → Expired
/ Superseded.

## What this affects

Due and expiry dates appear on the project [Calendar](../calendar/overview.md).

!!! note "Automated extraction is not currently available"
    Delivery documents are not automatically extracted or populated from
    contract or subcontract AI analysis today — entries are added manually.
