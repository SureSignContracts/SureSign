# Document Management Process

## Purpose

Get a file into SureSign, and later find, view, and download it.

## Role required

Any authenticated user with access to the project — Client accounts can
upload and delete documents too, not just Admin/Super Admin.

## Steps

1. [Upload the document](../documents/uploading.md) into the correct
   [folder](../documents/folders.md).
2. [Preview it](../documents/previewing.md) to confirm it uploaded correctly
   (where the file type supports inline preview).
3. [Download it](../documents/downloading.md) whenever you need the original
   file.

## Expected result

The file is stored against the project, viewable (or downloadable) by anyone
with access, and appears in your organisation's document views.

## Linked modules

- [Documents](../documents/overview.md)
- [Delivery Documents](../delivery-documents/overview.md)

## Common mistakes

- Uploading to the wrong folder — check the destination folder shown in the
  upload dialog before confirming.
- Assuming every file type previews inline — Word documents and some other
  types are download-only.

## What to do next

If this document satisfies a [delivery document](../delivery-documents/overview.md)
requirement, update that entry's status to match.
