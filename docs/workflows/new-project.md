# Create a Project

## Purpose

Set up the workspace for a new piece of construction work.

## Prerequisites

Know the project name, and ideally its contract type, type of work, value, and
dates.

## Role required

Any authenticated user in your organisation — Client accounts can create a
project too, not just Admin/Super Admin. See
[Creating a Project](../projects/creating-a-project.md).

## Steps

1. Go to **Projects** → **New Project**.
2. Enter the Project Name (required) and, optionally, a Project Number/Code.
3. Optionally choose a Project Type and Your organisation's role on this
   project.
4. Select **Create Project**.

Contract Type, Contract Value, Status, dates, and Description are
deliberately left for later — add them from **Edit Project** on the new
project's Overview page whenever you're ready. See
[Creating a Project](../projects/creating-a-project.md) for the full detail.

## Expected result

A new project appears in your project list, with a full workspace (Overview,
Contracts, Commercial, Variations, Notices, Programme, Delay & EOT, Risk
Register, RFIs, Meetings, QA Reports, Snagging, Site Reports, Delivery
Documents, Closeout, Documents, Calendar, and Adjudication if enabled).

## Notifications

The project appears in relevant dashboard tiles for your organisation's users.

## Common mistakes

- Skipping the project code where your organisation relies on one to
  distinguish similar project names.
