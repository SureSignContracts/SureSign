# Complete a Forced Password Change

## Purpose

Regain full access to SureSign after an administrator has required you to set
a new password.

## Role required

Any signed-in user this has been applied to.

## Steps

1. Sign in with your current or temporary password.
2. SureSign shows the **Change your password** screen instead of your normal
   workspace.
3. Enter and confirm a new password (minimum 8 characters, mixed case, numbers,
   and symbols).
4. Select **Update password**.

## Expected result

You are taken into SureSign as normal. Your previous sessions (if any) were
already ended when the reset was triggered, so this is now your only active
session.

## Common mistakes

- Trying to navigate elsewhere before changing your password — every other
  route is blocked until this step is complete, except signing out.
