# RFI Process

## Purpose

Raise a formal question and track it through to a recorded response and
closure.

## Role required

Super Admin or Admin.

## Steps

1. [Create the RFI](../rfis/creating-an-rfi.md) — subject, question, priority,
   raised date, and response-required-by date.
2. Wait for or chase a response ahead of the due date, using the
   [Calendar](../calendar/overview.md) to track it.
3. [Record the response](../rfis/responding-and-closing.md).
4. [Close](../rfis/responding-and-closing.md) the RFI once resolved.

## Expected result

The RFI moves Open → Responded → Closed, with the response text recorded
against it.

## Linked modules

- [RFIs](../rfis/overview.md)
- [Calendar](../calendar/overview.md)
- [Meetings](../meetings/overview.md) — RFIs are often discussed in progress
  meetings

## Common mistakes

- Letting an RFI sit past its response-required-by date without following up —
  check the Calendar's Overdue filter regularly.

## What to do next

Check whether the RFI's answer affects the [Programme](../programme/overview.md)
or requires a [Variation](../variations/overview.md).
