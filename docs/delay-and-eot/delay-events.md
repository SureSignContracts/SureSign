# Delay Events

## What this is

A record of something that has caused, or may cause, delay to the works.

## Where to find it

Project → **Delay & EOT** → **Delay Events** tab.

## How to record a delay event

1. Select **Create Delay Event**.
2. Enter the event details (title/description, cause, relevant dates).
3. Note responsibility for the delay and any evidence you have.
4. Save.

## Statuses

| Status | Meaning |
|---|---|
| Open | Recorded, not yet assessed. |
| Under Assessment | Being reviewed. |
| Closed | Assessment complete and accepted. |
| Rejected | Not accepted as a valid delay event. |

Status is set directly when you create or edit the event — there is no
separate "assess" button; update the status as your assessment progresses.

## Generated documents

A delay notice can be generated from a delay event, where your contract
requires formal notice of delay.

## What this affects

- A delay event can be the basis for an [EOT Request](extension-of-time.md) or
  a loss and expense claim.
- Delay events can affect [Programme](../programme/overview.md) milestones.
