# Extension of Time (EOT) Requests

## What this is

A formal request for additional time to complete the works, usually linked to
one or more delay events.

## Where to find it

Project → **Delay & EOT** → **EOT Requests** tab.

## How to submit an EOT request

1. Select **Create EOT Request**.
2. Link the relevant **Delay Event**, if applicable.
3. Enter the days claimed, grounds, and relevant dates.
4. Save as Draft, or submit directly.

## Statuses

| Status | Meaning | Set by |
|---|---|---|
| Draft | Being prepared. | Created this way |
| Submitted | Formally raised. | Submit |
| Under Assessment | Being reviewed. | Update |
| Granted | Extension agreed — decision recorded. | Decide |
| Refused | Extension not agreed — decision recorded. | Decide |

## Generated documents

An EOT decision notice can be generated once a decision (Granted or Refused)
has been recorded.

## What this affects

- A granted EOT can move dates on the [Programme](../programme/overview.md).
- Related loss and expense may be claimed alongside an EOT request.
