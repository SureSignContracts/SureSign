# Closeout

## What this is

A checklist for closing out a project: defects liability, test certificates,
O&M manuals, as-built drawings, final account, and handover, tracked to
completion.

## Who can use it

Any authenticated user with access to the project — including the Client
role, not just Admin/Super Admin — can manage closeout items.

## Where to find it

Project → **Closeout**. A closeout checklist with a standard set of default
items (Defects Liability, Test Certs, O&M Manuals, As-builts, Final Account,
Handover) is created automatically the first time you open this page for a
project.

## What you will see

- An overall **percentage complete** and a progress bar.
- Items grouped into categories, each showing its own completed/total count.
- Each item has a status toggle (a quick pending ⇄ completed switch) and a
  status dropdown for finer control: **Pending**, **In Progress**,
  **Completed**, **Approved**.

## Adding an item

Select **Add Item** and enter a **Category**, **Title**, and optional **Due
Date**, then save.

!!! note
    Once added, an item's category, title, or due date cannot be edited or
    deleted — only its status can be changed. Double-check the details before
    saving a new item.

## Marking the project complete

Select **Mark Project Complete** once all items are complete. This is disabled
until every item has been marked complete.
