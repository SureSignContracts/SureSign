# Status Reference

Statuses mean different things in different modules — do not assume "Draft" or
"Closed" behaves the same everywhere.

## Payment Applications

Draft → Submitted → PN Issued / PLN Issued → Certified → Paid (final).
Cancelled is available only from Submitted/PN Issued/PLN Issued (final).
See [Payment Applications](../commercial/payment-applications.md).

## Final Account

Draft → Submitted → Under Review → Agreed → Signed → Final Certificate Issued
→ Commercially Closed. Agreed, Signed, Final Certificate Issued, and
Commercially Closed are locked — figures cannot be edited from these states.
See [Final Account](../commercial/final-account.md).

## Variations

Draft → Submitted → Instructed → Quoted → Assessed → Approved (final) /
Rejected (can be resubmitted). See [Variations](../variations/overview.md).

## RFIs

Draft, Open, Pending Response, Responded, Closed. See [RFIs](../rfis/overview.md).

## EOT Requests

Draft, Submitted, Under Assessment, Granted, Refused. See
[Extension of Time](../delay-and-eot/extension-of-time.md).

## Delay Events

Open, Under Assessment, Closed, Rejected. See
[Delay Events](../delay-and-eot/delay-events.md).

## Risks

Open, In Progress, Resolved. See [Risks](../risks/overview.md).

## Snagging

Open → In Progress → Ready for Review → Closed. See
[Snagging](../snagging/overview.md).

## QA Reports

Draft, Open, Failed, Passed, Closed. See [QA Reports](../quality/qa-reports.md).

## Meetings

Draft, Issued, Approved. See [Meetings](../meetings/overview.md).

## Site Reports

Draft, Submitted, Approved. See [Site Reports](../site-reports/overview.md).

## Delivery Documents

Required → Pending → Submitted → Under Review → Approved / Rejected →
Expired / Superseded. See [Delivery Documents](../delivery-documents/overview.md).

## Closeout Items

Pending → In Progress → Completed → Approved. See [Closeout](../closeout/overview.md).

## Adjudication Cases

Draft, Notice of Dispute, Notice of Adjudication, Adjudicator Appointment,
Referral Submission, Response Analysis, Further Submissions, Decision
Analysis, Enforcement, Closed (or Archived, separately). See
[Adjudication](../adjudication/overview.md).

## AI Analysis (Contract and Subcontract)

Pending → Processing → Completed → Confirmed. Failed and Cancelled can occur
at various points. See [AI in SureSign](../ai/overview.md).

## Contracts

Draft, Active, Expired, Complete, Terminated. See [Contracts](../contracts/overview.md).

## Projects

Active, On Hold, Completed, Cancelled. See [Projects](../projects/overview.md).
