# Button and Action Reference

| Action | Where used | What it does |
|---|---|---|
| Create / New | Most modules | Opens a form to add a new record. |
| Save / Save Draft | Most create forms | Saves the record, usually in Draft or an initial status. |
| Update / Save Changes | Edit forms | Saves changes to an existing record. |
| Submit | Payment Applications, Variations, EOT Requests, Final Account | Moves a draft record into the formal assessment process. |
| Withdraw | Payment Applications | Returns a submitted application to Draft, keeping the same number, for correction. |
| Cancel | Payment Applications | Ends the application's process entirely (final; only from certain statuses). |
| Certify | Payment Applications | Records the certified amount; generates a Payment Certificate. |
| Mark Paid | Payment Applications | Records payment as made (final). |
| Instruct / Quote / Assess / Approve / Reject / Resubmit | Variations | Move a variation through its lifecycle. |
| Issue (Payment/Pay Less) Notice | Payment Applications | Generates and records a formal notice. |
| Release | Retention | Releases retention for a moiety or a manual adjustment. |
| Agree / Sign / Issue Final Certificate / Commercially Close | Final Account | Progress the Final Account through its locked lifecycle stages. |
| Confirm & Save Analysis | AI review screens | Confirms AI-extracted data as current for the contract/trade package. |
| Re-run / Re-parse | AI analysis | Starts a fresh analysis, or reprocesses a saved response at no extra cost. |
| Generate Brief | AI analysis (confirmed only) | Produces a Contract Intelligence Brief PDF. |
| Generate (PDF/Excel) | Various commercial and document records | Produces a downloadable document. |
| Preview | Documents | Opens an inline preview where supported. |
| Download | Documents | Downloads the original file. |
| Close | RFIs, Adjudication Cases | Marks a record as finished. |
| Advance Step | Adjudication Cases | Marks the current step complete and moves to the next. |
| Archive | Adjudication Cases | Moves a case out of the active list. |
| Mark Project Complete | Closeout | Marks the whole closeout checklist as complete. |
| Mark as Read / Mark all as read | Notifications | Clears the unread state on one or all notifications. |
| Reset Tour | Help | Replays the guided product tour. |
| Invite | Team | Sends an account invitation with a chosen role. |

Only actions that actually appear in the current interface are listed here. If
you see a button not listed here that is greyed out or labelled "Coming soon,"
it is not yet a working feature.
