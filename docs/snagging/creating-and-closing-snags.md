# Creating and Closing Snags

## How to create a snag

1. Select **Create**.
2. Enter a **Title**, **Description**, and **Location**.
3. Choose a **Category** and **Priority** (Low, Medium, High, Critical).
4. Choose a **Status** and, if known, an **Assigned To** person.
5. Enter a **Due Date** and any **Notes**.
6. Save.

## Statuses

| Status | Meaning |
|---|---|
| Open | Identified, not yet actioned. |
| In Progress | Being worked on. |
| Ready for Review | Fix completed, awaiting sign-off. |
| Closed | Confirmed resolved. SureSign records the date it was closed. |

## Closing a snag

Change its status to **Closed**. SureSign automatically records the closing
date/time when this happens.

## Editing and deleting

Snags can be edited at any time, and deleted with a confirmation prompt.

## Filters

Use the search box and status/priority filters on the Snagging list to find
specific snags.
