# Snagging

## What this is

A register of defects ("snags") found on a project, tracked from identification
to close-out.

## Who can use it

Any authenticated user with access to the project — including the Client
role, not just Admin/Super Admin — can create and manage snags.

## Where to find it

Project → **Snagging**.

## In this section

- [Creating and Closing Snags](creating-and-closing-snags.md)

## Statuses

Open → In Progress → Ready for Review → Closed.

## Priority

Low, Medium, High, Critical.
