# Creating a Trade Package

## Who can do this

Super Admin and Admin users.

## Where to find it

Open a project's **Contracts** page and use the "New trade package" or "Create
first trade package" action, which opens the trade package generator.

## How to create trade packages

1. Choose one or more **standard packages** from the catalogue (for example
   Groundworks, Brickwork, M&E, Roofing) using the checkboxes. Packages already
   on the project are shown disabled/marked "exists." A **Select All** option is
   available.
2. To add a package not on the standard list, tick **Other** and enter a
   **Custom package name**. SureSign generates a short code from the name's
   initials automatically.
3. Review the **package reference preview**, which shows the generated
   reference (project reference + package code) for each package you are about
   to create, with a "Custom" tag on custom entries.
4. Submit.

## What happens after you save

- SureSign creates each selected trade package with its reference and standard
  folder structure.
- Packages that already existed on the project are reported as "skipped," not
  duplicated.
- You can generate multiple packages in a single action rather than one at a
  time.

## Common mistakes to avoid

- Re-running the generator expecting to recreate a package that already
  exists — it will be skipped, not duplicated or reset.
- Choosing a custom name that generates the same short code as an existing
  package — SureSign appends a numeric suffix to keep it unique, so double
  check the generated reference before relying on it in external
  communication.

## What to do next

Open the new trade package and begin
[subcontract onboarding](subcontract-onboarding.md).
