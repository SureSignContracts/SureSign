# Trade Package Workspace

## What this is

Opening a trade package takes you into its own workspace, similar in spirit to
a project workspace but scoped to that one subcontract package.

## Where to find it

From a project's Contracts or Commercial area, open a specific trade package.

## Tabs in the workspace

| Tab | What it covers |
|---|---|
| Overview | Summary of the trade package |
| Commercial | Payment applications and commercial records for this package |
| Programme | Milestones and timeline specific to this package |
| Delay & EOT | Delay events and extension of time for this package |
| Compliance | Compliance-related tracking for this package |
| Documents | Delivery documents for this package |
| AI Analysis | Subcontract AI analysis history and actions — see [Subcontract Analysis](../ai/subcontract-analysis.md) |
| Activity | Activity log for this trade package |

A risk register scoped to the trade package is also available from this
workspace.

## How this connects to the project

Commercial and programme records inside a trade package are separate from the
project's main contract records — for example, a trade package can have its
own payment applications, distinct from payment applications raised against
the main contract. Documents and risks can exist at either the project level or
the trade package level, depending on what they relate to.
