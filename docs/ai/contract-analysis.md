# Contract AI Analysis

See [Contracts: AI Analysis](../contracts/ai-analysis.md) for the full
step-by-step guide to starting, reviewing, and confirming a contract analysis.

In short:

1. Upload the contract document.
2. Start analysis.
3. Review the extracted summary, fields, workflows, documents, dates, risks,
   and missing items.
4. Correct anything that needs it.
5. Confirm the analysis so its data becomes available elsewhere in SureSign
   (for example, seeding programme milestones).

Once confirmed, you can generate a **Contract Intelligence Brief** — a PDF
summary of the confirmed contract information.
