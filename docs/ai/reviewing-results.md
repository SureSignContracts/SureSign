# Reviewing AI Results

The review process is the same for contract and subcontract analysis. See
[Contracts: Reviewing AI Results](../contracts/reviewing-ai-results.md) for the
full walkthrough of the sections you will see (summary, fields, workflows,
documents, dates, risks, missing items) and how to correct values before
confirming.

## Key points

- Nothing is applied to your contract or trade package until you
  [confirm](../contracts/confirming-analysis.md) the analysis.
- If confirming would overwrite existing data, SureSign warns you first.
- You can always go back to a past analysis from its
  [history](../contracts/analysis-history.md).
