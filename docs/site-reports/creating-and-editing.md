# Creating and Editing a Site Report

## How to create one

1. Select **New Site Diary**.
2. Enter the diary **Date**, **Weather**, and **Workers on Site**.
3. Enter **Works Carried Out**, **Materials Delivered**, and any **Issues /
   Delays**.
4. Choose a **Status** (Draft, Submitted, Approved).
5. Select **Save Diary**.

## How to edit one

Open an existing site report and select **Edit**. The same form opens
pre-filled with its details; make your changes and select **Save Changes**.
Client accounts can create, edit, and save site reports the same as
Admin/Super Admin.

## Workforce breakdown (optional)

Once a site report has been saved, you can optionally record an
approximate breakdown of who was on site by trade or role — e.g. "Site
Supervisor — 1", "Labourer — 4". This is entirely optional and
supplementary: **Workers on Site** remains the overall figure that
matters, and recording a breakdown never changes it. If your breakdown
total doesn't match Workers on Site, SureSign shows both figures without
treating it as an error — it may simply mean you've only recorded part
of the picture. This breakdown feeds the Friday Pack's Workforce
section — see [Friday Packs](../friday-packs/overview.md).
