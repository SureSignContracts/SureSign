# Creating and Editing a Site Report

## How to create one

1. Select **New Site Diary**.
2. Enter the diary **Date**, **Weather**, and **Workers on Site**.
3. Enter **Works Carried Out**, **Materials Delivered**, and any **Issues /
   Delays**.
4. Choose a **Status** (Draft, Submitted, Approved).
5. Select **Save Diary**.

## How to edit one

Open an existing site report and select **Edit**. The same form opens
pre-filled with its details; make your changes and select **Save Changes**.

Client users see a read-only version of this form and cannot save changes.
