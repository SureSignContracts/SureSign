# Notices

## What this is

A single page bringing together three kinds of formal, dated project
correspondence: EOT Requests, Pay Less Notices, and Site Instructions.

Delay Notices are not a tab here. Delay events have their own dedicated
record type, with full create, edit and delete plus generate-notice, on the
project's [Delay and Extension of Time](../delay-and-eot/overview.md) page.

## Who can use it

Super Admin and Admin create, issue and manage notices. Client users can
view them.

## Where to find it

Open a project and select **Notices** from the project sidebar. Use the tabs
across the top to switch between the three record types.

## The three tabs

- **EOT Requests** — requests for additional time. See
  [Extension of Time](../delay-and-eot/extension-of-time.md).
- **Pay Less Notices** — a notice of intention to pay less than a notified
  sum. See [Pay Less Notices](../commercial/pay-less-notices.md).
- **Site Instructions** — a formal instruction issued on site, for example an
  instructed variation, a safety instruction, or a design change. Give it a
  title, a type (Variation, Safety, Quality, Design, General, or Urgent), who
  it's issued to, the date, and a description. Select an existing instruction
  to view, edit or delete it.
